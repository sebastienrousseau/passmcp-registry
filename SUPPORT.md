# Support

| You want to | Go to |
|---|---|
| Stop your server being checked | [OPT-OUT.md](OPT-OUT.md) |
| Question a published verdict | an [issue](https://github.com/sebastienrousseau/passmcp-registry/issues) naming the server and the record |
| Report a vulnerability in passmcp-registry | [SECURITY.md](SECURITY.md) |
| Understand how a verdict is reached | [docs/method.md](docs/method.md) |
| Understand how findings go to owners | [DISCLOSURE.md](DISCLOSURE.md) |

A finding that looks wrong is usually passmcp's to fix: the scorecard
publishes passmcp's verdict unchanged. Reproduce it with the command in the
record's method, and report it to
[passmcp](https://github.com/sebastienrousseau/passmcp/issues) if it holds.

passmcp-registry is maintained by one person alongside other work. Issues are
read weekly; opt-out requests are acted on before the next run.
