## Highlights ⭐️

* **In lockstep with passmcp 0.0.7 and passmcp-reporting 0.0.7**: the family's seventh release. passmcp-registry did not ship a 0.0.6, so it moves from 0.0.5 straight to 0.0.7, and the scorecard now runs passmcp 0.0.7, whose `protocol.deprecated_features` check no longer warns a server that serves both protocol generations.
* **Built with Go 1.26.9**: the `go` directive moves from 1.26.8, which `govulncheck` reports as reachable by ten standard-library advisories in `net/http`, `crypto/tls`, `os` and `net/textproto`, to the release that fixes them.
* **`make versions` checks DEVELOPMENT.md**: its passmcp install line had been left behind a release, because the check only read the README and `docs/`. It now covers it.
* **The manual fails on a page left out of its navigation**: the 0.0.5 highlights were published but unlisted, and the strict build only logged it. Such a page is now a warning, which fails `make manual` and the Manual workflow.
