## Highlights ⭐️

* **Fuzzed registry listings**: A fuzz target feeds arbitrary registry pages to the listing parser and checks that only a named server at a plain http(s) URL, with no template and no credentials, is ever put on the check list.
* **Fuzzed withholding decisions**: A fuzz target feeds arbitrary passmcp reports to the disclosure rules and checks that every withheld result names one of the four DISCLOSURE.md rules and quotes a bounded amount of server text.
* **One family version**: passmcp-registry moves to 0.0.3 with passmcp and passmcp-reporting. The scorecard's method is unchanged.
