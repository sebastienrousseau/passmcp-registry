## Highlights ⭐️

* **A signed scorecard of the MCP Registry**: Every remote server in the official registry is checked read-only and without credentials by a pinned passmcp release, and each result is published as a signed, offline-verifiable in-toto statement.
* **Owners come first**: A result that would hand an attacker a way in is withheld and queued for the owner under a 90-day disclosure policy, and any owner can opt out.
* **Reproducible numbers**: The yearly report publishes its raw data under CC-BY-4.0, with every figure traced to the signed records it came from.
