## Highlights ⭐️

* **One site, published together**: The manual, the coverage badge and the scorecard under `/scorecard/` are now deployed by one workflow, so a scorecard run no longer overwrites the manual or the other way round.
* **A manual and its reasoning**: The documentation is a rendered manual with an architecture overview and decision records for how the scorecard is run and published.
* **One family version**: The scorecard requires passmcp-reporting's v0.0.1 release instead of a pre-release commit, and moves in lockstep with the rest of the passmcp family.
